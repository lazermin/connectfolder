# connectfolder 2.0 — подключение сетевых каталогов SMB

Графическая программа для **РЕД ОС 8** (и других rpm-дистрибутивов с GTK 4):
добавляет, изменяет и удаляет сетевые каталоги SMB/CIFS, которые **autofs**
монтирует по обращению в `/media/share/<имя>`.

**Технологии:** Python 3 + GTK 4 (PyGObject). Компилировать ничего не нужно.

## Возможности

- Список каталогов со статусом доступности: сервер (порт 445), билет
  Kerberos, открытие каталога. Проверка идёт в фоне и **от имени текущего
  пользователя**, поэтому показывает то, что увидит он сам.
- Вход по имени и паролю или по доменной учётной записи (Kerberos,
  `multiuser,cruid=$UID,sec=krb5`). Если компьютер в домене (`realm list`),
  для новых каталогов по умолчанию предлагается Kerberos.
- Права на файлы для входа по паролю:
  - **только пользователь, открывший каталог** (`uid=$UID,gid=$GID,
    file_mode=0600,dir_mode=0700`), по умолчанию — другие локальные
    пользователи файлы не видят;
  - **все локальные пользователи** (`noperm`), как в версии 0.1.x;
  - без настройки (владелец root).
- Версия SMB: авто, 3.1.1, 3.0, 2.1, 2.0, 1.0 (с предупреждением).
- Только чтение, дополнительные опции `mount.cifs` (для новых каталогов
  сразу подставляется `iocharset=utf8` — для кириллицы в именах файлов).
- Сетевой путь в любом виде: `server/share`, `//server/share`,
  `\\server\share`, `smb://server/share`. Имя каталога подставляется само.
- Предпросмотр строки карты autofs до сохранения.
- Журнал выполненных действий (кнопка с терминалом).
- Перенос настроек версии 0.1.x.

## Где что лежит

| Путь | Назначение |
|---|---|
| `/etc/auto.connectfolder` | Карта autofs (0644). Чужие строки и комментарии сохраняются |
| `/etc/auto.master.d/connectfolder.autofs` | Подключение карты: `/media/share /etc/auto.connectfolder --ghost --timeout=300` |
| `/etc/connectfolder/credentials/<имя>` | Учётные данные mount.cifs (0600, каталог 0700) |

Если в `/etc/auto.master` нет строки `+dir:/etc/auto.master.d`, программа
её добавит. Перед изменением `auto.master` и карты сохраняется копия
`*.connectfolder.bak`.

## Перенос со старой версии (0.1.x и 0.2.x)

Выполняется автоматически при установке пакета (`%post`) и доступен из меню
☰ → «Перенести старую конфигурацию…». Если старые файлы найдены, в окне
появляется жёлтый баннер.

1. Каталоги из `/etc/auto.samba` переносятся в `/etc/auto.connectfolder`.
   Опции переводятся в новый формат, режим доступа остаётся прежним
   (`noperm`), чтобы у пользователей ничего не сломалось.
2. Пароли из `/root/.auth_smb/<имя>` переносятся в
   `/etc/connectfolder/credentials/<имя>` с правами 0600. Пароли со знаком
   `%` (на них падала старая версия) переносятся корректно.
3. Строка `/media/share /etc/auto.samba --ghost` в `/etc/auto.master`
   комментируется.
4. Старые файлы переименовываются: `/etc/auto.samba.connectfolder-migrated`
   и `/root/.auth_smb.connectfolder-migrated` (права закрываются до 0700/0600).
   Когда убедитесь, что всё работает, их можно удалить.
5. Строки, которые программа не распознала, переносятся как есть с
   комментарием. Каталог, имя которого уже есть в новой карте, пропускается.
6. `systemctl reload autofs`.

Если что-то пошло не так на любом шаге, все изменения откатываются.
Повторный запуск ничего не делает. Вручную:
`sudo /usr/libexec/connectfolder/connectfolder-helper --migrate`.

## Безопасность и права

Интерфейс работает от **обычного пользователя**: список и статус читаются
без root. Для изменений через `pkexec` поднимается помощник
`connectfolder-helper`. Пароль спрашивается один раз за сеанс, поэтому
программа работает и под Wayland.

Помощник умеет только: сохранить каталог, удалить каталог, отдать имя и
домен учётной записи (пароль из файла наружу не отдаётся), перенести
старую конфигурацию, подключить карту к autofs. Shell не используется,
все входные данные проверяются, запись атомарная с откатом.

Autofs после изменений **перечитывает** карту (`systemctl reload`), а не
перезапускается, поэтому открытые каталоги у других пользователей не
обрываются. Если служба не запущена, она включается (`enable --now`).

## Оформление окна

В GNOME (а также Budgie, Pantheon) кнопки находятся в заголовке окна
(HeaderBar). В MATE, KDE и прочих рамку рисует оконный менеджер, кнопки —
на панели под заголовком. Принудительно: `CONNECTFOLDER_CSD=1` или `=0`.

## Установка

### RPM (рекомендуется)

```bash
sudo dnf install rpm-build make
tar xzf connectfolder-2.0.0.tar.gz && cd connectfolder-2.0.0
make rpm
sudo dnf install ~/rpmbuild/RPMS/noarch/connectfolder-2.0.0-1.*.noarch.rpm
```

### Без установки, из папки

```bash
sudo dnf install python3-gobject gtk4 autofs cifs-utils polkit
python3 connectfolder_gui.py
```

### `make install`

```bash
sudo make install      # в /usr; удаление: sudo make uninstall
```

Помощник ищется в `/usr/libexec/connectfolder/`, затем рядом с программой.
Политика polkit привязана к установленному пути, поэтому при запуске из
папки pkexec покажет общий запрос пароля администратора.

## Демо-режим

```bash
make demo          # система не меняется
make demo-reset    # вернуть демо в состояние «после версии 0.1.x»
```

Демо работает в `~/.cache/connectfolder-demo-root/`: там лежат старые
`/etc/auto.samba` и `/root/.auth_smb`, на которых можно проверить перенос.
Системные команды (`systemctl`, `umount`) не выполняются, а только пишутся
в журнал.

## Требования

- GTK 4.6+ и PyGObject (РЕД ОС 8)
- Python 3.7+
- autofs, cifs-utils, polkit с графическим агентом
- для Kerberos: компьютер в домене (`realm join`) и билет у пользователя

## Структура

| Файл | Назначение |
|---|---|
| `connectfolder_gui.py` | Интерфейс GTK 4 |
| `connectfolder_core.py` | Логика без GTK: модель, карта autofs, учётные данные, миграция, клиент помощника |
| `connectfolder-helper` | Привилегированный помощник (pkexec) |
| `data/` | Запускающий скрипт, .desktop, политика polkit |
| `tests/` | Тесты и подготовка демо-корня |

## Изменения относительно 0.1.4

- Исправлено выполнение команд через shell от root с данными из полей ввода
  (`ping`, `su … bash -c`).
- Пароли хранились с правами 0644 — теперь 0600 в каталоге 0700.
- Редактирование и удаление шли по номеру строки в списке и могли
  испортить чужую строку `auto.samba`; теперь — по имени каталога.
- autofs перезапускался при каждом обновлении списка, в том числе при
  запуске программы, и обрывал открытые каталоги; теперь `reload` только
  после изменений.
- Пароль со знаком `%` ломал запись и чтение (`configparser`).
- Проверка доступности шла от root и блокировала окно; теперь в фоне и от
  пользователя, вместо ping — порт 445.
- Дубли строки в `auto.master`, `domainname -d` вместо `realm`, отсутствие
  проверки на занятое имя при переименовании и другие ошибки.
- Интерфейс переписан на GTK 4 и работает от обычного пользователя.
